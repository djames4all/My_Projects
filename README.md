## 🔧 Common Build Commands

### **.NET Projects**

    dotnet restore
    dotnet build
    dotnet run

### **Node.js / React Projects**

    npm install
    npm run dev
    npm start

### **Android (Kotlin)**

Open in Android Studio\
OR:

    ./gradlew assembleDebug
    ./gradlew installDebug
