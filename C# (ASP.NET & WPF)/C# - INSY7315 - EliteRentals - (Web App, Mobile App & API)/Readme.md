## 📖 Introduction
EliteRentals is a rental management system developed by **Fantastic 4** as part of the INSY7315 Work Integrated Learning project.  

The solution was designed for **Dr Majoko Projects (Pty) Ltd**, a growing real estate company in South Africa, to replace manual spreadsheets, ad hoc communication, and unstructured workflows with a **centralized, digital platform**.  

By combining a **web application** for Admins, Property Managers, and Prospective Tenants with a **mobile application** for Tenants and Caretakers, EliteRentals delivers:
- Seamless property listings and digital applications  
- Secure tenant and caretaker management with SSO and biometric login  
- Automated invoicing, arrears tracking, and payment acknowledgement  
- Structured maintenance request workflows with caretaker task boards  
- AI-enabled chatbot support in multiple languages  
- Real-time dashboards, analytics, and offline-ready features  

EliteRentals is more than just a project — it is a **scalable, professional-grade system** that empowers property managers, improves tenant satisfaction, and prepares Dr Majoko Projects for future growth.

## 🏠 Project Background
Dr Majoko Projects (Pty) Ltd is a growing real estate rental company in South Africa.  
Currently, operations rely on spreadsheets, manual filing, and ad hoc communication.  
This has led to:
- Late rental payments  
- Maintenance backlogs  
- Poor tenant satisfaction  

We developed **EliteRentals** to solve these inefficiencies and prepare the business for scale.

---

## ❗ Problem Statement
Key challenges faced by Dr Majoko Projects:
- No real-time tracking of rental payments or arrears  
- Lack of visibility into leases, expirations, and vacancies  
- No structured maintenance request system  
- Absence of a professional digital presence for tenants  
- No centralized communication record  

---

## 🎯 Project Goal
To design and implement an **integrated rental management system** across web and mobile platforms, enabling:
- Digital property listings  
- Secure tenant management  
- Real-time rent tracking  
- Structured maintenance workflows  
- AI-enabled support services  
- Detailed reporting

## ✅ Project Objectives
- Interactive **web portal** for property manager, admins, and prospective tenants
- **Mobile app** for tenants and caretakers with offline-ready features  
- Secure login with **SSO** and **biometric authentication**  
- Automated rental invoicing, arrears tracking, and payment acknowledgement  
- Property listings with digital applications for prospective tenants  
- Lease lifecycle tracking with renewal alerts  
- Structured maintenance request workflows  
- Full Multilingual support across the entire mobile app (English/Zulu)  
- Admin dashboards and downloadable reports  
- Offline mode with local storage and sync-on-connect

## 📦 Scope of the System
**In-Scope Functionalities:**
- Web-based admin dashboard  
- Tenant mobile app with chatbot and offline sync  
- Secure login (SSO + biometrics)  
- Property listing and rental application workflow  
- Lease and invoice automation  
- Maintenance request lifecycle management  
- Role-based access (Admin, Property Manager, Caretaker, Tenant)  
- Push notifications and multilingual messaging  
- REST API + RoomDB   

---

## 🔑 Expanded Features
- **Authentication & User Access:** SSO, biometrics, RBAC, user preferences  
- **Property Listings:** Search, filter, images, maps, secure applications  
- **Lease Management:** Metadata, expiry tracking, renewal reminders, archives  
- **Rent & Payment:** Auto-invoices, proof uploads, overdue alerts  
- **Maintenance:** Categorized requests, caretaker task board, status updates  
- **AI Chatbot:** FAQs, arrears summaries, escalation to human support  
- **Push Notifications:** Firebase Push Notification integration  
- **Reporting & Analytics:** Dashboards, PDF reports, filters  
- **Offline Access:** RoomDB sync with conflict resolution  
- **Multilingual Support:** English + one South African language  
- **Communication:** Secure messaging, announcements, email integration

## 👥 User Roles
| Role              | Key Actions                                                                 |
|-------------------|------------------------------------------------------------------------------|
| **Admin**         | Manage users, oversee operations, send broadcasts, handle escalations, reports |
| **Property Manager** | Manage properties, leases, tenants, payments, maintenance, escalations       |
| **Tenant**        | View leases, pay rent, report issues, upload proof, chatbot interaction       |
| **Caretaker**     | Resolve maintenance tasks, update statuses, upload notes/photos               |
| **Prospective Tenant** | Browse listings, apply online, upload documents, receive confirmations       |
